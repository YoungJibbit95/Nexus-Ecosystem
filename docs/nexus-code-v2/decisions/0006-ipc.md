# ADR 0006 — Typed domain ports over validated native IPC

Status: Accepted target decision, 2026-09-30. No IPC implementation changes in Wave 0.

## Context

Preload exposes explicit methods with useful validation; main/services enforce canonical roots and process/Git restrictions. Renderer components infer capabilities and handle mixed throws/primitives/result objects directly. Main registration is concentrated and lacks a common senderFrame validator.

## Decision

Introduce strict TypeScript window/workspace/runner/Git/GitHub/LSP ports, structured result/error/capability schemas and disposable event subscriptions. Adapt existing API shapes before changing preload. Main remains authority for sender, payload, root, environment and operation policy; preload checks supplement it. Split domain registration after behavioral parity. No raw IPC channel or Node object enters UI.

## Consequences and verification

Unsupported browser operations return unavailable, never generated success. Public errors are actionable/scrubbed; diagnostic details are separately retained without secrets. Characterize missing bridge, throws/results, oversize/invalid payloads, outside paths and event teardown. Retain full JS typecheck failure while requiring a strict noEmit gate for new boundaries. Wave 1 begins with compatible ports, not wholesale native rewrite.
