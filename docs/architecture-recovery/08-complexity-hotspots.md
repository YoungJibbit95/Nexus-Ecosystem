## Hidden synchronization and compatibility layers

**Notes:** editor draft → idle/debounce commit → app-store mutation → debounced IndexedDB queue → transaction. UI “saved” is tied to a store action, not the final step. The draft reset effect keys on active ID, so a same-ID restore can leave old text in a mounted draft. A future extraction must capture identity plus external revision. [E06,E12]

**Code:** editor event → active refs → code-commit timer → file array/tab dirty flags → separate local-storage queue, or native workspace write. The LSP engine has its own document version for protocol correctness; it should not become a second persistence owner. [E08,E21]

**Workspace:** app/canvas/workspace stores → independently saved records → manual snapshot/export. Restore reverses this with direct setters. Main's unreferenced automatic hook is not another active writer, but reintroducing it would add one and must be treated as a feature/lifecycle change. [E09,E10]

**Views:** shared manifest → remote availability → client fallback/allowlist → local registry → mounted view cache → executable-command filter. The lists express different facts, but their relationships are implicit. A visible route is not proof that every declared command has a handler. [E03,E04]

These chains are stronger evidence of architectural debt than the number of files involved. Main also has a verified configuration/preload/DevTools dependency loop with a lazy import: see [03](03-dependency-ownership-map.md#boundary-violations-that-matter) and E31. No runtime circular-import defect was demonstrated; type-only imports and conceptual feedback paths must not be mislabeled as synchronous module cycles.

## CSS evidence and preservation plan

PostCSS found `.nx-notes-unified-status-action .nx-notes-format-toolbar` in **18 root-context rules** at lines 7516, 7716, 11444, 11982, 13652, 13954, 14227, 14584, 15033, 15185, 15696, 15930, 16404, 16660, 16856, 16938, 17209 and 17836. These are not simply the same selector in different responsive media queries. Other Notes selectors also recur repeatedly.

This supports cascade debt, not an assertion that every repeated property is incorrect. Before deleting or moving declarations, capture Notes toolbar/title/status behavior across themes, reduced motion, narrow/wide and short-height viewports, zoom and focus modes. Compare computed layout/visibility as well as screenshots. Preserve winning order in the first extraction; remove superseded declarations only after equivalence is demonstrated.

Large generated catalogs, language registries, test fixtures and declarative settings renderers are not automatically god objects. For example, Code `languageIds.js` and the visual-smoke fixture are large but do not independently establish competing state ownership.
